# Kick it with Fab 🏈⚽🏀

**Your Ultimate Sports Destination** - A modern, responsive sports blog built with React, TypeScript, and cutting-edge web technologies.

## 🌟 Features

### 🎯 **Core Functionality**
- **Latest Sports News**: Comprehensive coverage of NFL, NBA, MLB, Soccer, Tennis, and Athletics
- **Interactive Sliders**: Swiper.js powered hero sections and content carousels
- **Smooth Animations**: Framer Motion animations throughout the site
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Admin Panel**: Full content management system for blog posts
- **SEO Optimized**: Complete SEO setup ready for custom domain

### 🚀 **Technical Stack**
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom animations
- **Animations**: Framer Motion + Swiper.js
- **Icons**: Lucide React
- **Forms**: React Hook Form with Yup validation
- **Routing**: React Router DOM v7

### 📱 **User Experience**
- **Hero Slider**: Full-screen animated hero with featured stories
- **Category Filters**: Interactive filtering with smooth transitions
- **Like & Bookmark**: Interactive engagement features
- **Search Functionality**: Real-time search with animations
- **Newsletter Signup**: Animated subscription forms
- **Social Sharing**: Built-in social media integration

## 🔧 **Setup & Installation**

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/kickitwithfab/sports-blog.git

# Navigate to project directory
cd sports-blog

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production
```bash
# Build the project
npm run build

# Preview production build
npm run preview
```

## 🌐 **Custom Domain Setup**

### DNS Configuration
When you purchase `kickitwithfab.com`, configure these DNS records:

```
Type: A
Name: @
Value: [Your hosting provider's IP]

Type: CNAME
Name: www
Value: kickitwithfab.com
```

### SSL Certificate
- Enable HTTPS/SSL through your hosting provider
- Update all internal links to use HTTPS
- Configure HSTS headers for security

### SEO Migration
- Submit new sitemap to Google Search Console
- Update Google Analytics property
- Set up 301 redirects from old URLs
- Update social media profiles with new domain
